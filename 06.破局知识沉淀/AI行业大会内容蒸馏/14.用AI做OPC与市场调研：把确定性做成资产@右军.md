# 用AI做OPC与市场调研：把确定性做成资产@右军
> **整理依据**：本教程基于右军这场关于「用AI做OPC」的现场演讲整理——已完整看完全程、逐页核对关键课件画面，并结合本地音频转写校对讲师原话。它**不是逐字稿**，而是一份「读得懂、能判断、能填写、能验证」的训练型材料：每一章都配了判断标准、自检问题或可以直接填写的表格。讲者右军，在蚂蚁金服工作14年、程序员出身，运营20多万订阅的技术公众号「技术琐话」，现在主做自媒体IP与企业AI咨询培训，并孵化了500位个人IP。
> **阅读目标**：读完并完成文中的自检与填空后，你要能判断**自己到底具不具备做OPC（一人公司）的条件**，并写出一份「把确定性做成资产」的第一版行动草案——知道下一单从哪来、哪些环节自己抓、哪些环节找搭档换。

## 先给你一个结论：这场课真正要训练什么
大多数人一听到「2026全员OPC」，第一反应是：我去学个AI工具，写几段文案、做几张图，就能一个人开公司赚钱了。这场课要把这个念头整个掰正。右军讲得很直白：**不是AI不行，是大部分人根本没摸到AI创业的门槛**。真正的分水岭不在工具，而在你会不会做生意、能不能把一次性的劳动沉淀成可复制、可定价的资产。
所以这场课训练的，是一套「先看需求、再看确定性、最后用确定性换不确定性」的思维顺序。下面这张表，先帮你把「普通人的做法」和「这场课教的做法」对照清楚——后面每一章都在把右边那一列讲透。

## 一、先认清扎心事实：为什么90%的人做不成OPC
右军开场就抛了一个第三方咨询机构对某城市（比如杭州）OPC从业人员的调查数据：**80%的OPC，月收入就在几千块钱**。确实有做到十万、百万的，但那是极少数，二八原则依然牢牢管着这个群体。这不是打击你，而是让你先摘掉「一个人开公司很轻松」的滤镜。
他用一个特别扎心的对比戳破幻觉：**你自己在家做OPC赚到1万块，和你在公司上班拿到1万块，是同一个等级的事吗？不是。**
在公司拿1万，是你在一个专业岗位上、靠积累拿到的报酬，讲的是「深度」。作为一个开发、测试、产品或销售，你不需要去想：公司为什么做这个产品？需求从哪来？客户在哪里？市场竞争怎么样？——这些是老板在想。你的1万块，是这个岗位的定价，你做好一颗螺丝钉就行，真正扛焦虑和风险的是老板。
而你自己干、剩下1万块，意味着你已经跑通了「从客户需求→获客→营销→转化→产品/服务交付→维护」这一整个闭环。**同样是1万块，这个难度至少比上班高5倍。**
右军还让你把创业成功率摆正：你看那些做上市、很光鲜的团队，那是**百分之一**的可能性；更多是没做起来、做得很一般的。今天做OPC，成功率会比传统创业稍高一点，但也绝不是很高——你能做到**十分之一**吗？也就是百分之几的几率。先认清这个事实，你才不会被「学个技能就能躺赢」的叙事带偏。右军反复强调：**学习技能只是第一步，只是第一步。**
> 判断标准：想知道自己离OPC有多远，别问「我会不会用AI」，先问自己——上面那条闭环里的六个环节（需求、获客、营销、转化、交付、维护），你亲手独立跑通过几个？跑通过4个以上，你才算摸到了门槛；只会其中一两环（比如只会做内容、只会写代码），你现在还是在「用工具」，不是在「做生意」。

## 二、别再谈资源：资源是「你对别人有用」
右军说，经常有人来找他谈合作，开口就是「我有很多资源，能不能帮企业做点啥」。这类对话他其实不太愿意花时间——因为创业之后**你最宝贵的就是单位时间，一天十个小时，花出去就没了**。
他给「资源」重新下了定义，这句话值得你抄下来：
> 资源不是你认识多少大佬，不是你在谁的群里，也不是你有多少好友关系。**资源是你对别人有用、有价值。是你对人家有用，不是人家对你有用。**

所以正确的开场不是「我有资源」，而是「我发现了什么需求、我能帮你解决什么问题」。哪怕你自己没有交付能力，只要你能**发现需求、把需求讲清楚**，就能和有交付能力的人合作——你做撮合、做牵线，别人做交付，一起把事情做成。这也是后面「联盟」的地基。
> 避雷：有人跟右军说「我在某行业生根三十年，我很强，想合作」。右军只回一个问题——**你生根之后的结果是啥？你今天找到了几个具体需求？需要我做点啥？**「我很强」不是资源，「我手上有5个待解决的付费需求」才是。你在别的赛道很强，也不代表你做AI培训就很强，到了新赛道，同样得从小学生做起、恭恭敬敬入局。

右军还把事情拆成两半看：如果你**有交付能力**，那就直接去发现需求、做交付；如果你**没有交付能力、但能发现需求并把需求讲清楚**，那你就做撮合、做牵线——你出需求，别人出交付，一起把这一单做成。两条路都成立，唯独「我认识很多人」这一条不成立。用下面两句话给自己做个诚实体检：
- [ ] 我最近一次向别人开口合作时，说的是「我发现了X需求」，而不是「我认识很多人/我有很多资源」
- [ ] 我能具体说出，我对我想合作的那个人，究竟有什么用、能帮他解决什么
## 三、灵魂三问：用第一性原理替代「我有资源」
怎么把「谈资源」的坏习惯改成「谈价值」？右军给了一个第一性原理的「灵魂三问」（其实是四问），这是你每接触一个方向都要先过一遍的筛子。
1. **你发现了什么需求**——是真实存在、有人愿意掏钱的痛点，还是你自己臆想的？
2. **你的用户是谁**——谁做购买决策、谁掏钱？
3. **你对他提供什么样的帮助**——你交付的具体价值是什么？
4. **你为此能收多少钱**——这个价值能定价、能变现吗？
右军特别强调一个反直觉的点：看一个业务，**不是先看你用哪个AI工具、会不会用AI，而是先看有没有赚到钱；而"先看有没有赚到钱"的本质，是先看需求是什么。**广场舞大妈要买保险，她的需求可能是对健康的期待、也可能是缺少陪伴；老师要用AI，需求是内容创作和备课减负。不同的人对AI的期待完全不同，**本质永远是先挖掘需求——AI只是工具，它不会帮你定价、获客、谈单，那是老板定规则、工具执行规则。**
现在就把你的方向填进这张卡，填不满的地方就是你还没想清楚的地方：

| 灵魂三问 | 你的答案（填写） |
|---|---|
| 我发现的需求是什么 |  |
| 掏钱的用户具体是谁 |  |
| 我提供什么帮助 |  |
| 我能收多少钱 |  |

> 顺带纠正一个常见幻想：有位朋友说「我这县城没人讲AI课，我有制造业、生物医药的客群，我是AI小白但学习能力强，想一个月成为讲师」。右军的回答是**不可能**——你今天是AI小白，凭啥一个月教别人？讲师、咨询师本身至少是中等难度的事。你得先在一个专场（AI视频、智能体、直播、带货、数字人挑一个）用它拿到结果，**球都踢不好，怎么当教练？先做好运动员，再做教练。**纯小白老老实实3到6个月增强技能，才谈得上转型。

## 四、做成OPC的四个硬条件（逐条给自己打分）
这是全场的核心骨架。右军说，2026年全世界都在喊全员OPC，但要真做成，你得同时满足四个条件——**第一条决定你能不能开始，后面几条决定你能走多远**。下面每一条都配了自检，请一条条对自己诚实打分。
### 条件一：你会不会做生意（第一条，决定你能不能开始）
前面第三章讲透了——做生意的起点是需求，不是工具。你能不能独立看懂一个需求、把它变成收入，是第一道门槛。**过不了这一条，后面三条都不用谈。**
- [ ] 我能说清我要服务的人群，最真实、最愿意掏钱的那个需求是什么
- [ ] 我判断一个项目时，先看需求和有没有人掏钱，而不是先纠结用哪个AI工具
### 条件二：你是不是在卖时间
右军拿自己举例：他讲课一天课时费5000到1万，听起来不错，但一个月30天不可能天天讲——身体吃不消、需求也没那么多，而且客户A和客户B需求有差异，每次都要备课。他为了讲一天课，加上差旅和准备，可能要花掉4到5天。**只要你卖的是时间，天花板就一目了然。**
> 判断标准：问自己一句——**你能不能从「做一次赚一次」变成「做一次赚一百次」？**如果你的收入必须靠你本人到场、开口、动手才产生，你就被时间锁死了。这不是说不能卖时间起步，而是你心里要清楚天花板在哪，并且知道下一步要把它产品化（见第六章）。

### 条件三：你有没有抗风险的能力
右军见过太多人「头脑一发热」：我伺候老板不开心，不干了，要自己创业搞OPC。他反问：你有没有想过，**如果3到6个月你都没赚到钱，你还能不能生活、能不能养家糊口？**如果没有这个Buffer，千万不要贸然辞职。
> 正确姿势：**边上班边探索副业，让它先长起来**——相当于你一边打工一边给自己攒试错空间。就像你想开饭店，也该先和人合伙搞个小的试试，否则一下投几十万，很可能打了水漂。抗风险能力不够就别all in，这是纪律，不是胆量问题。

### 条件四：你会不会用「AI员工」、会不会造工具
右军说，大部分人用AI工具很容易，但真正的高手是在**搭建自己的工作流、搭建自己的知识库**——这是很大的区别。一句话总结这一条：
> **普通人在拼AI工具，高手拼的是AI商业和自己造AI工具。**工具人人会用，但把工具串成属于你的工作流和知识库，才是别人抄不走的壁垒。

## 五、从OPC到团队：一个人的天花板在哪
右军把话说到底：**即使你满足了四个条件，OPC仍然有天花板，因为一个人的时间总是有上限。**时间、品类、交付、客户范围、复利，五个维度都会卡住你。
> 一句话记住定位：**OPC适合从0到1的验证，从1到100必须靠团队。**OPC是起点，团队化才是终点。AI降低了执行成本，但决策和关系还得靠人来做。从OPC走向团队，不是你失败了，反而是一次进化。

右军也坦诚讲了自己的两次卡点，作为真实参照：第一次，他从职场辅导起步，做到一百多人后遇到「知识付费增长放缓」，而且很多人职场这条路本身快走到头（行业下坡、年龄受限），于是他把咨询切换成「带大家做IP和AI副业」，一个人交付不过来就找了搭档文姐和圣哥，把IP孵化做到了500人。第二次，做企业培训时又遇到新卡点——客户需求多样、前期销售成本高、交付质量不稳。他的应对，就是下一章要讲的「产品化 + 标准化」。
这里有一个你能直接借用的组织方法：右军团队有一百多位讲师，面对新技术（从Deep Research到各种新模型）总有新需求，他们靠**公开课不收钱、破局城市主局**让新讲师去锻炼，锻炼后在内部评审、做模课，再用**老带新**的方式持续优化。但他补了一句很关键的话——**共创如果没有主心骨，就是耍流氓**。共创不是大家七嘴八舌之后各说各的ABC，而是要有人做统筹和判断：让大家参与，但民主要集中。这一条，后面第七章谈联盟时还会再强调一次。

## 六、把确定性做成资产：市场调研、产品化与标准化
这一章是本场的「资产」题眼——**核心思维是从卖时间走向卖产品**。右军帮一个客户搭一套AI内容生产系统，这是卖一份时间；但他会追问：能不能把交付给这个客户的东西**抽象出来**？于是他去**调研更多的场景**，把系统产品化，做成能让100个客户都用的工具。**这里的市场调研，就是你把一次性经验升级成可复制资产的关键动作——先看清同类客户的共性需求，再决定把什么固化下来。**
他自己的实践是企业AI培训标准化：同一套「AI通识」课程，可以适配金融、制造、零售等不同行业客户，于是就变得可复制、可定价、可规模化。但他特别提醒一个分寸——
> 判断标准：产品化不等于100%僵化。右军的课**70%内容是固定的，30%做行业特性的案例**。这样既有很强的可复用性，又能满足不同行业客户的差异。所以别僵化地理解产品化，你要在「标准化」和「可扩展性」之间找融合点。你卖的东西不一样，产品化的定义就可以不一样。

更进一步，他把整条链路都SOP化了：标准化获客的内容矩阵、培训体系、从他自己讲到团队分角色交付，课程研发→讲师培养→客户交付→效果评估，形成流程化。这时候他做决策要不要开发一门新课，看的是**复购率**——复购率低就不接，否则会陷入纯外包模式。
> 现在轮到你：想一想你最近做过的一次交付（一次咨询、一条视频、一套方案），试着回答——它有没有可能被抽象成一个「70%固定 + 30%定制」的产品？固定的70%是什么？请写下来，这就是你第一块「确定性资产」的雏形。

判断一件事值不值得产品化，右军其实只用一个硬指标——**复购率**。不是所有需求都要接，接一个只做一次、之后再没人复购的定制单，你就把自己拖回了纯外包。用下面两条给你手上的业务过一遍：
- [ ] 我能指出自己业务里，哪一块是「70%可固定、能卖给多个同类客户」的部分
- [ ] 我在决定要不要接一个新需求时，会先看它的复购率，而不是只看这一单的钱

## 七、用确定性换不确定性：联盟的三种组合
右军讲了一句本场最凝练的方法论，请重点记住：
> **组合（联盟）的本质，是用我自己的确定性，去换合作伙伴那边的不确定性；再用合作伙伴的确定性，换掉对我这边的不确定性。降低的是什么？试错成本。一切皆有成本。**

为什么要联盟、而不是自己硬学、硬组一个大团队？因为当你在跑MVP、试错阶段，你只会软件研发、只会Web coding，但不知道客户从哪来、不会做流量，这时候去组建大团队很难——那是大公司的打法。正确的顺序是：**先贴着脸去刷脸，营销身边的朋友、找到有需求的人，先做一单看、交付两单三单，有感觉了，再把自己不擅长的模块外包或找联盟解决。**
> 判断标准（分数原则）：把你最强的80分、90分的能力抓在自己手里，这是你的长处；但其他几条线，你至少得达到**五六十分**——因为你如果完全不理解整个闭环，就很难带领团队、也没法判断搭档干得好不好。别人可以补你的短板，但你不能对短板一无所知。

右军给了三种经过验证的联盟组合，对照看看你适合哪一种：

| 组合类型 | 怎么搭 | 真实例子 |
|---|---|---|
| 技术超级个体 + 行业专家 | 懂AI的和在行业生根多年的搭伙 | 江门一位财税专家AI不熟，但生根十年、懂行业漏斗和客群，和AI强的伙伴合作做财税/保险智能体，两天一夜大课送工具，转化很快 |
| IP流量 + 产品交付 | 会做小红书/视频/直播的，和有后端交付的合作 | 流量型博主自己没有好产品，就对接有知识付费或线下产品的交付方 |
| 资源撮合 + 执行团队 | 撮合方负责挖需求，执行团队负责落地 | 右军的「文胜军」组合：文姐擅长私域、圣哥擅长文案与社群运营、他自己做产品设计与定位，闭环打通 |

> 关键原则：资源撮合的能力不是「我认识谁」，而是**「我拿到了5个需求，痛点是什么、需要什么方案、谁能帮到我」**。而且组合一定要**先谈好分钱**——共创如果没有主心骨就是耍流氓，民主要集中，得有一个人做统筹和判断，让大家参与但不各说各话。

## 八、行动指南：三个自检 + 往团队走的三步
什么时候该从OPC升级到团队？右军给了三个非常具体的自检问题，一个个问自己：
1. **你的收入是否被时间锁死？**你睡觉时有没有收入？不去见客户、不去上课有没有收入？如果没有，说明你还在纯用时间换钱，没用好组织杠杆。
2. **你的客户是否排队等你？**看你的需求有没有超过你的交付能力。超过了，就说明你需要人手了。
3. **你是否在重复造轮子？**每个项目都从零开始？如果是，说明你还是外包项目的形态，需要产品化。
> 判断标准：这三个问题，**只要有两个甚至三个答案是「Yes」，就说明你该找搭档、组团队了。**

确认要走团队化之后，右军给的路径是清晰的三步：
- [ ] 第一步：产品化验证——先把一个能复用的产品跑通、验证复购
- [ ] 第二步：找搭档、找联盟——用第七章的三种组合补齐短板
- [ ] 第三步：组建团队——形成「快速组织、对新事物敏感、小兵团作战」的模式
右军用自己团队的OpenAI训练营佐证了「快 + 质量过硬」：3月4号推出、几乎没做宣传，本想只交付内部客户（预估200-500人），当天就过1000人，靠学员自主分销最后到了4000人。他们是**教练团组好、文档还没写就开始卖**，四个教练每天干到凌晨两三点，写了大几万字SOP、做了五六场直播、后来沉淀成录播。**要快，但质量要过硬。**紧接着团队又推出WorkerBody方向的训练营，同样做到1000人参加。
为什么能一推就爆？右军点破了背后的因果：**因为踩到了风口**——这个方向在那段时间有大的流量、更多人想学习，而他们很早就推了出来。这正好呼应了他后面讲的第一条观点「提前量就是红利」。从这个案例里，你要提炼出的可复用动作是三个词：**快速组织、对新事物敏感、小兵团作战**。别等万事俱备——教练团组好、需求验证到了，就可以边卖边把文档和交付补齐，用真实订单倒逼你把SOP写出来。

## 九、普通人不是没有机会：右军的三点观点
有人问：普通人是不是没机会了？右军的回答很明确：**不是，普通人缺的只是更好的起点和路径。**
> 普通人怎么开始？**不要一上来就重投入，而是先找到一个风险低、系统化、适合起步的入口，边学边调整。**包括你的定位，也不是一次到位的，可以不断尝试、持续迭代——先建立AI的知识体系和常见工具逻辑，再在实战行动里边学边调。

右军最后把他这些年沉淀的三条观点交给你，作为这场课的收束：
1. **提前量就是最大的红利**——很多风口项目最终大家都能看到空间，但能提前半年判断出来，就有巨大的时间差和更多机会窗口。
2. **线下的面对面在AI时代反而更关键**——大量合作是在线下谈成的，走到哪儿就在哪儿组织聚会，场域的沟通不可替代。
3. **成功从来不是偶然**——当一个组织长期做「认知 + 方案 + 案例 + 环境」，成功就是自然跑出来的结果。创业不只拼技能差和认知差，更需要心力、愿力和一群同心者。
右军也复盘了「为什么一个体系能持续跑出案例」，这对你选择起点很有参考价值：它不是靠制造焦虑，而是实实在在做交付——包含认知（对风口的洞察）、案例、方法的拆解，还有长期、高频的实战场景训练。更关键的一点是**成才率**：他看到很多伙伴从学员做到助教、志愿者，再成为下一届的教练——当一个组织愿意把优秀的学员变成教练、大家都愿意共建和贡献内容时，它就不再是「一家公司的成功」，而是几万人集体的成功。
> 选起点的判断标准：一个值得你投入的入口，应该同时具备四样东西——**对风口有提前判断（认知）、有可复用的方法拆解、有真实案例、有能持续练手的环境**。这四样齐了，你的成长就不靠运气。反过来，只贩卖焦虑、没有真实交付和练手场的地方，再热闹也别久留。
