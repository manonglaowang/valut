# 报告模板结构（profiles.json 字段 Schema）

`generate_reports.js` 读取 `data/profiles.json`（数组，每人一项），结合 `data/graduated_{id}.json`
（作业数据，自动算星级/日期），渲染每位学员一份两页 A4 PDF。

本文件说明 **profiles.json 每个字段的含义与可改项**，供 Agent 撰写或使用者微调。

---

## 整体结构

- **第 1 页 · 封面**：红底渐变品牌页
  - 顶部：行动营名称 + 「✓ 已毕业 · 上岸」徽章
  - 中部：姓名大字 + tagline 副标题 + oneliner 金句
  - 下部：4 个数据卡（stats）+ 年度关键词标签（keys）
  - 底部：私享说明
- **第 2 页 · 内容页**：白底信息密集页
  - 00 打卡地图（热力格，自动按时间升序，红=3★满星 / 浅粉=2★达标）
  - 01 能力画像 · 五维雷达（bars）+ 02 星级成长曲线（自动，含每点数值）
  - 高光时刻（hl 金句 + hlWho 出处 + grit 咬牙）
  - 03 小成果墙（achievements 芯片网格）+ 04 学员侧写（profile 三卡）
  - 数据条（打卡天数 / 平均星级 / 满星次数 / 最强维度，自动计算）
  - 结营寄语（wish）

---

## profiles.json 字段定义

```jsonc
[
  {
    "id": "星球编号",            // 必填，须与 graduated_{id}.json 对应
    "name": "微信昵称",           // 必填，用于文件名与标题
    "key": "yoyo",               // 可选，HTML 文件名用；缺省用 id
    "campName": "破局行动营",     // 可选，封面/页脚行动营名；缺省用脚本 DEFAULT_CAMP
    "volunteer": "白兰度",        // 可选，页脚署名；缺省「行动营志愿者」
    "tagline": "在工具泥潭里一次次爬起来的「死磕型」",   // 封面副标题
    "oneliner": "用 12 天，把总想放弃的自己熬成能跑的生产线。", // 封面金句
    "stats": [                                            // 4 个数据卡
      { "v": "12次", "k": "打卡" },
      { "v": "2.5★", "k": "平均星级" },
      { "v": "6次", "k": "满星作业" },
      { "v": "5.0", "k": "坚持韧性" }
    ],
    "keys": ["死磕", "流水线思维", "API", "排雷"],          // 3–6 个关键词
    "hl": "如果内容连自己都打动不了，肯定无法打动用户。",     // 高光金句（学员原话）
    "hlWho": "第10天（7/19）· 账号改了方向仍守住内容品质",     // 高光出处
    "grit": "卡在飞书机器人对接五六小时，想放弃又咬牙坚持。",  // 咬牙瞬间
    "bars": [                                              // 五维能力（1–5 分）
      ["工具攻坚", 4.0], ["方法论", 3.0], ["商业化", 2.5],
      ["坚持韧性", 5.0], ["输出质量", 3.5]
    ],
    "achievements": [                                      // 小成果墙（8–12 项）
      "跑通 Codex 中文显示", "飞书机器人死了又救终上线", "…"
    ],
    "profile": [                                           // 学员侧写三卡
      { "l": "你是一个什么样的人", "t": "认准了就不撒手的死磕型行动者…" },
      { "l": "你擅长什么", "t": "把零散工具串成能跑的生产线…" },
      { "l": "你的潜力", "t": "内容品质的坚持+工具链手感…" }
    ],
    "wish": "你最值钱的不是某篇作业，是那种见缝插针也要学的劲…"  // 结营寄语
  }
]
```

> 星级、日期、打卡天数、平均星、满星次数、最强维度 **均由脚本从 graduated_*.json 自动计算**，
> 无需在 profiles.json 里手写——上面 stats 里的 `v` 仅作封面展示文案，可自由表述。

## 设计语言（可改项）

- **品牌色**：红 `#d63031` / 暖橙 `#e17055`（封面渐变与强调色）。改色只需改 `generate_reports.js` 里的 CSS。
- **字体**：`Noto Sans SC / PingFang SC / Microsoft YaHei`（依赖系统已装）。若无中文字体，打印 PDF 会缺字——需先装中文字体。
- **尺寸**：固定 A4 竖版 210×297mm，封面满版、内容页两网格平衡布局填满整页。
- **信息密度**：内容页用双网格（雷达|曲线+高光 / 成果墙|侧写）确保等高、无半页空白。

---

## 常见问题

- **想换文案但不想重提作业**：直接改 `data/profiles.json`，再跑 `node scripts/generate_reports.js` + `node scripts/print_pdfs.js`。
- **想改配色/布局**：编辑 `generate_reports.js` 内的 `CSS` 常量与模板字符串。
- **想加模块**（如学习轨迹时间线）：在模板字符串里加区块，并在 profiles.json 增加对应字段。
