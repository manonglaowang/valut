## 二、课程大纲（痛点驱动型，洋哥第5步法）

### 课程定位
这不是一个AI工具课。这是一个工作流课。
目标是让每个学员在21天内跑通一条自己的AI工作流——从需求分析到Skill沉淀，再到自动化执行。

### 大纲结构

**模块一：认知重塑 — 为什么你用了AI但没效果（3天）**
```
Day 1｜AI提效的真相：不是你不会用，是你没用对地方
Day 2｜找到你每天的高频重复任务（动手练习：列出你的Top 10重复工作）
Day 3｜判断一个任务适不适合AI的三个标准
```
痛点：用AI很久但没结果，不知道从哪里切入。
产出：学员完成自己的「高频重复任务清单 + AI适配评分」

**模块二：工具实战 — Claude Code 和 Codex 的真实用法（5天）**
```
Day 4｜Claude Code 入门：不是你想象的那样写代码
Day 5｜实战：让AI帮你读一个陌生代码模块
Day 6｜实战：让AI帮你改一个真实的bug
Day 7｜实战：让AI帮你写一个自动化脚本
Day 8｜验收：如何判断AI给你的代码能不能用
```
痛点：AI写代码看起来很厉害，但自己用起来总是不对。
产出：学员完成1个自己的AI辅助开发案例（读代码/改bug/写脚本三选一）

**模块三：Skill 沉淀 — 把经验变成AI可复用的能力（5天）**
```
Day 9｜Skill不是提示词：理解Skill的本质
Day 10｜拆解你的第一个Skill：从一个重复任务开始
Day 11｜写Skill的四个步骤（模板直接给）
Day 12｜实战：把你的测试用例生成流程写成Skill
Day 13｜Skill验收：怎么判断一个好Skill
```
痛点：每次让AI干活都要重新解释，经验没有沉淀。
产出：学员完成1个自己的Skill（测试用例生成 / bug分析 / 报告生成 三选一）

**模块四：工作流搭建 — 把单点变成闭环（5天）**
```
Day 14｜工作流思维：不是你用AI，而是AI帮你跑
Day 15｜实战：搭建你的第一条AI工作流
Day 16｜让工作流可复用：模板化+参数化
Day 17｜日常维护：工作流不是一次性的
Day 18｜复盘：我的工作流哪里还可以优化
```
痛点：只会单点用AI，没有形成持续的提效系统。
产出：学员完成1条完整的AI工作流（从输入到输出可重复执行）

**结营：成果验收 + 后续路径（3天）**
```
Day 19｜学员成果路演（每人5分钟展示自己的Skill/工作流）
Day 20｜从训练营到日常：怎么持续维护和迭代
Day 21｜结营：下一步怎么走（社群陪跑方案介绍）
```
产出：每个学员带走1个Skill + 1条工作流 + 1份持续维护计划
