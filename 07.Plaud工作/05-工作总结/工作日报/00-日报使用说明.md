# 工作日报使用说明

> 当前阶段原则：实习期转正优先，IP 沉淀第二。日报首先服务于工作交付、向上同步、转正证据积累和 [[06-2026下半年OKR]] 对齐。

## 日报要解决的问题

每天写日报不是为了记流水账，而是为了让自己和主管都能快速看清四件事：

1. 今天最重要的工作目标是什么。
2. 交付物是什么，怎么验收。
3. 哪些风险、依赖和阻塞需要尽早暴露。
4. 哪些经验可以沉淀为后续复用资产。
5. 今天的任务是否偏离 2026 下半年 OKR。

## 每天固定节奏

上午开始工作前，先写：

- 今日转正目标
- OKR 对齐检查
- 今日关键交付
- 时间节点
- 已知风险与依赖

下班前补齐：

- 实际完成结果
- 证据链接或文件路径
- 沟通结论
- 明日计划
- 可选 IP 素材

## 写作标准

- 用交付物说话，不只写“推进了”“沟通了”。
- 每个关键事项都要有验收标准，例如脚本路径、报告路径、日志需求结论、对齐人和截止时间。
- 风险提前写，不等失败后再解释。
- IP 素材只记录副产物，不影响当天主线工作。
- P0 / P1 任务必须标注 OKR：`O1`、`O2`、`O3` 或 `日常支撑`。
- 如果一天的 P0 / P1 全是 `日常支撑`，需要提醒自己补一个能推动 OKR 的最小动作。

## 日报结构

1. 今日转正目标
2. OKR 对齐检查
3. 今日关键交付
4. 时间节点
5. 实际进展
6. 风险与依赖
7. 沟通与协同
8. 明日计划
9. 可沉淀素材

## 命名规则

文件名使用 `YYYY-MM-DD.md`，例如 `2026-07-27.md`。

每周做周报时，优先从日报里提取：

- 本周完成的可见交付
- 本周解决的问题
- 本周暴露的风险
- 下周需要主管支持的事项
- 能体现转正价值的证据
