## 这个项目在做什么

Plaud QA pytest 自动化测试工程，承接 Sigma（能录音的 TWS 耳机 + 4G 充电盒）的固件冒烟、回归、协议、BLE 联动、APP 联动、FOTA 和长稳测试。核心链路：

```
script(用例) → actions/scene(场景编排) → actions/single(原子动作) → logic(协议/session/client) → core
```

真机测试栈：串口/继电器治具 + DebugAnalyzer UART 抓包 + iOS WDA 元素树直连（已淘汰 Midscene AI 识图）。

## 复盘时的使用方式

1. 遇到"这个坑是不是踩过"——先查 [[01-硬件实测踩坑知识]] 和 [[02-Skill沉淀清单]]。
2. 新人/新会话接手前——按顺序读 04 → 03 → 02 → 01，从宏观到具体。
3. 这份沉淀是某一时刻的快照，源项目仍在演进；具体代码路径、参数以仓库当前状态为准，本文档只保证"发生过什么、为什么"这一层不丢失。
