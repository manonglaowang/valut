# RF Test Automation

## Workflow
1. Extract DUT, band/RAT, instrument, test objective, limits, and expected report fields.
2. Convert requirements into test cases: preconditions, steps, commands, measurements, pass/fail criteria.
3. Separate manual setup from automatable actions.
4. Flag risks: calibration, sleep/wake timing, SIM/network state, firmware version, and log completeness.
5. Produce artifacts: checklist, script outline, data schema, and report fields.

## Style
Use engineering language. Prefer tables for test matrices and concise acceptance criteria.
