# AI Skill Course Builder

## Workflow
1. Identify audience: executives, engineers, testers, customers, or beginners.
2. Define one transformation promise: what they can do after the course.
3. Build structure: pain point → concept → live demo → exercise → SOP → next action.
4. Include before/after comparisons from real engineering workflows.
5. Prepare deliverables: agenda, slide outline, demo script, exercise files, and FAQ.

## Principle
Teach workflows, not tools. Every module should end with a reusable prompt or skill pattern.
