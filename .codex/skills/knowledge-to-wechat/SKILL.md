# Knowledge To WeChat

## Workflow
1. Extract the core audience pain point and one useful takeaway.
2. Choose angle: story, tutorial, opinion, case study, or checklist.
3. Translate jargon into scene-based language while preserving technical correctness.
4. Structure: hook → conflict → method → example → reusable template → call to action.
5. Add title options, summary, and tags.

## Voice
Practical, engineer-to-engineer, with concrete before/after examples.
